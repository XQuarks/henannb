### 1. 地块有机化（治「四四方方」）
- **根因**：固定图种子摆在规整网格上，Voronoi 切出来就是棋盘格。
- **试过治本的路（放弃）**：加大种子抖动。实测 `pairGate` 沿中心连线采样 12 点做穿水校验（容差 1 点），
  斜对角边最长最脆 —— JIT 0.12→0.16 就掉 1~3 条边，0.22 掉到只剩 70%（桥图最惨）。连通性虽然还在，
  但拓扑变了会影响寻路手感。**结论：抖动保持 0.12 不动拓扑。**
- **正解（渲染层做弯）**：`drawPath(poly, wob)` 把每条边切成两段、中点沿法线推开 `L*0.13`。
  偏移量 `edgeWob()` 由「这条边两个端点（排序后）」做 FNV 哈希 → 相邻地块共享的同一条边算出**完全相同的偏移**，
  既不会裂缝也不会互相压色；端点排序保证 a→b 与 b→a 同值（否则法线方向会反过来）。
  **只改绘制、不动 poly 数据** → 邻接 / pairGate / 点击判定 / 面积全部不受影响。
- 调用点：地块投影 5063 / 铺色 5077 / 描边 5082 / 焦土 5093，**湖泊 5110 也必须一起弯**（湖岸与地块共享边）。

### 方法论（写给自己）
**「地图不好看」这类视觉问题，先看能不能在渲染层解决，别急着动生成数据。**
邻接只依赖中心点、不依赖多边形边长什么样 —— 所以画的时候把边做弯，是零风险换取观感的最优解。
反过来，动生成数据（加大抖动）哪怕只掉几条边，也是在改玩法。

## 第四批续二：参考图学习（去规整 + 障碍物）+ UI 两处

### 黎总给了 8 张参考图（State.io 等）+ 四条要求

### 参考图学到的五件事
格子大小差异极大（大的 3~4 倍于小的，大格子是主场、小格子是走廊）/ 山体障碍群直接堵在地图中间 /
水体嵌在地图内部而不只是外圈海 / 轮廓是有机 blob / 装饰压在格子上增加质感。

### 1. UI 两处
- **删 #tip**（底部常驻操作提示横幅，纯静态无 JS 引用），CSS 一并清掉，留注释指路 git 历史
- **技能/半兵按钮加文字**：改成「图标 span + 文字 span」双层结构。坑：`hudSet` 用 `textContent` 写按钮，
  会把标签一起抹掉 → 动态内容（冷却倒数）必须改写到内层 `#skillIco`；display 从 block 改 flex。
  按钮加高 52→64（移动端 46→58），halfBtn bottom 146→158 让位。

### 2. 格子大小变化：非等距网格线（axisPos）
- 相邻列/行间距带随机权重（0.64~1.36），由 rng 派生 → 同图每次一致；跨度归一化回 n-1 不撑出屏幕。
- 只改「间距」不改「顺序」→ _g 拓扑照旧。
- 实测大小比 1.7~2.6（原来约 1.2）。

### 3. 行交错（STAG）：大坑，见下
- 奇数行整体横移 0.17（砖缝错位）。
- **矩阵实验结论（重要）**：STAG 任何 >0 的值都会破坏终章「三方到 Boss 2/2/2 对称」——
  交错把斜向边的 pairGate 采样点推到四格共享顶点之外 → 斜边被掐 → 跳数变化。
  amp（非等距）则完全不影响对称。
  | amp | stag | 大小比 | 终章对称 |
  |-----|------|--------|----------|
  | 0.36 | 0.17 | 1.9 | 0/4 ✗ |
  | 0.36 | 0 | 1.7 | 4/4 ✓ |
  最终：amp=0.36 保留；**交错只用于非终章图**（h10/g10/b10/d10 加 `even:true` 禁交错）。

### 4. 山体障碍（新字符 ^）
- `^` 与 `~` 一样进 LAKES —— **阻挡逻辑零改动**（inLake/pairGate 原样生效）；
  另用 `MOUNTAINS`(Set) 记引用，渲染时水 pass 跳过、单独画岩石堆（clip 在山体格内，深色底+6~10 块不规则岩石）。
- 重置点：LAKES 清空的三处都要同步 `MOUNTAINS=new Set()`。
- **障碍摆放铁律：障碍格斜邻一条重要斜向路线就会掐断它**（山的多边形touching四格顶点）。
  终章图摆山前先用搜索器试位（对每个 v 格临时换 ^ 重建、看三方跳数是否保持 2/2/2），
  even 间距下每张图有 13~15 个安全位，选分散的两个。

- 桥关四张：岸上 1~2 座山点缀（江不动）

### 经验
**「加障碍」不是改显示，是在改图论。** 一个格子从陆地变障碍，所有以它为斜邻的斜向边都可能消失。
