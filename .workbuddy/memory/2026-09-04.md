## 地图整体重设计提案（待黎总拍板，未动代码）

- 基于黎总提供的 7 张同类游戏（State.io 类）地图截图做视觉分析，产出 `docs/MAP-REDESIGN-PROPOSAL.md`。
- 核心设计：
  - **大陆架轮廓层**：外形（S1~S6 海岸线模板）与骨架（M0~M5）拆成两层正交组合；S6 三角洲可偿还 M2 空心三叶旧债。
  - **一族一世界**：人类沃土田园 / 哥布林荒原峡谷 / 天龙灰烬高地 / 矮人雪山矿脉，每族生态五件套（水色/地色/障碍/装饰簇/粒子），BIOMES 表驱动纯渲染换肤。
  - **地理叙事线**：每族 10 关 = 一条地理路线（人类边境→国门、哥布林商路→金库、天龙龙巢→君临、矮人凿山→低头），L1/L4/L7/L10 同质档位按此差异化。
  - **生态专属机制 ×4**：麦田丰收 / 商队路过 / 岩浆喷发 / 矿洞隧道（隧道成本最高，备降级方案）。
  - **交互**：地图放大 30~50 格 + 常驻相机（单指拖空白平移、双指捏合缩放、双击复位），一指派兵红线不破；小地图 P1。
  - **装饰**：山体按生态换肤 + 结构驱动成脉分布；背景深炭工业风 → 生态水面 + 海岸白边。
- 批次规划：A 地基（轮廓+放大+相机）→ B 生态换肤（预览先行）→ C 叙事落地（按族四小批）→ D 导航。
- 风险已列：单局时长红线、小屏性能（装饰离屏缓存）、雪原浅色生态的领地辨识度。
