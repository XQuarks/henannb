## 踩坑（重要，同类问题以后必查）
- **TDZ P0**：`MID_EDIT.__revive = ...` 原先写在 `const MID_EDIT = {}` 声明之前 → 整页脚本加载即 `ReferenceError: Cannot access 'MID_EDIT' before initialization`，游戏白屏。已把挂载点移到 `const MID_EDIT` 之后。
  - 教训：向「注册表对象」挂载函数时，必须先确认 `const` 声明位置。e2e 的 `eval(js+DRIVER)` 能直接抓到这类加载期崩溃。
- 测试断言踩坑：`spawn` 不传 `at` 时才回落到「容量最大据点」，传 `at:'base'` 走的是 `pop` 最大据点，断言对象会错；`fn` 未注册时 `midExec` 返回 0 → 序列**直接收尾**（midBusy=false），不是挂起。
