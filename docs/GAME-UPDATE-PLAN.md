# 游戏更新方案 · 战役重构与叙事演出（v2 总方案）

> **概述**：本文是《统一之路》下一阶段的总更新方案，取代 `CAMPAIGN-REDESIGN-TABLE.md`（v1，其内容已全部并入并扩展）。三件事：**①三族关卡重构去同质化**（桥关×4、三塔×3、巨城×3、驻军攻坚×4、斩首×3、七兵营×2、敌预占×3）；**②地图与玩法新机制**（潮汐浅滩/沙暴龙卷/冰面冻伤/飞行兵种/特殊建筑）；**③叙事演出系统**（局中运镜反转、胜利尾声、败局反转接续战）。人类线（C1 已落地）本轮补演出并小改 3 关（含教学关）。
> **前提**：战役 40 关全部**固定手图**（沿用 M6 手写网格管线），随机生成退居二线、后议；自由对战不在本方案范围。
> **状态**：仅方案，未动代码（2026-09-04）。批次 C 未完成的差异化项与生态专属机制（商队/喷发/隧道）全部保留并编入。
> **关联**：`MAP-REDESIGN-PROPOSAL.md`（生态/轮廓/相机地基）、`LEVEL-DESIGN-PROPOSAL.md`（40 关盘点）、`GAMEPLAY.md`（红线）。

**红线自查**：一指派兵手势不动；新机制全部复用「兵球/战利品箱/人口产能」既有体系，不新增局内资源；飞行兵用既有建筑产出与克制链平衡；局中演出不打断操作（暂停只用于剧情节拍，且可跳过）。

### 1.3 局中叙事演出系统（导演触发器 v2）

现有管线：开场分镜 `dir`、对白卡 `dlg`、终局演出 `finale`、常驻相机 `cam`、toast/Sfx。升级为**局中触发演出**——每关可配若干条：

```
midCine: [{ trigger, seq:[...] }]
```

- **触发器**：`onCapture(类型/编号)` 占领某点 / `onTime(t)` 计时 / `onHpBelow(目标,%)` 目标驻军跌破阈值 / `onGold(n)` 战利品到额 / `onAlmostDefeat()` 玩家基地濒危 / `onAllianceBreak()` 盟友反水

- **演出元素（seq 顺序执行）**：`slowmo(0.25×,1.2s)` 子弹时间（新增 timeScale，复用 bannerSlow 思路）/ `pause` 暂停 / `cam(焦点,缩放)` 运镜（复用常驻相机）/ `vfx(金光/火柱/尘浪)` / `dlg(说话人,台词)` 导演对白卡 / `mapEdit` 地图变更 / `spawn` 增援 / `buff` 全军增益

- **地图变更类型**：开路（浮桥升起/浅滩露出/密道塌出）、reveal（新区域/新目标出现）、spawn（援军/野怪）、机制开关（喷发失控）

> 原则：演出不锁玩家操作（pause 仅限 2s 内剧情节拍、可点击跳过）；每关演出 ≤3 处，宁缺毋滥。

## 8. 风险备忘

1. \*\*隧道（⑨）与飞行兵（⑤）\*\*都动移动层，是全方案最贵的两项；隧道有降级方案，飞行兵可降级为「仅限 L5 剧情助战、不可量产」；
2. \*\*败局反转（㉓）\*\*分叉结算流程，务必先 1 关试点跑通再推广，且反转只给「可翻盘的资源」不给「保送」；
3. **演出密度**：每关 ≤3 处，全部可跳过——演出是佐料，别挡操作；
4. \*\*1v1（⑲）\*\*先花半小时验证三方假设，有硬伤则矮人 L9 退回「斩首+旋转对称图」；
5. 手图工作量：三族约 15 张新图+人类 6 张手图化，建议每族先出 1 张验证管线效率再批量。
