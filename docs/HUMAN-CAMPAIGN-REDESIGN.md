# 人类线重设计提案 · 王土保卫战（10 关）

> **概述**：把人类战役 10 关整体重做一遍——每关「剧情 = 玩法 = 地图 = 美术」四件事咬合，各有一个能记住的钩子。**L1 基础教学**，**L2 堡垒关**（新机制「关隘堡垒」：部分道路只有占领堡垒才能通过），其余 8 关各配一个新机制或新美术效果。
> **状态**：**提案阶段，未动 `index.html`**。本文只设计，不含代码改动；落地批次见第 7 章，开工前需黎总逐批拍板。
> **读者**：黎总（看第 0、1、2、7 章拍板）、策划（第 3~6 章）、开发（第 6 章机制表 + 第 7 章批次）。
> **关联**：`GAME-UPDATE-PLAN.md`（全战役总方案，机制编号 ①~㉔）、`MAP-REDESIGN-PROPOSAL.md`（生态/轮廓/美术地基）、`LEVEL-DESIGN-PROPOSAL.md`（40 关盘点）、`GAMEPLAY.md`（玩法红线）、`DEVELOPMENT.md`（代码锚点）、`ACTION-PLAN.md`（进度看板）。

**红线自查**：一指派兵手势不动；新机制全部复用「兵球 / 战利品箱 / 人口产能」既有体系，**不新增局内二级资源**；单局仍 ≤6 分钟；每关演出 ≤3 处且可跳过；不要求玩家读说明书（渐进提示优先）。

## 0. 结论先行

| 优先级 | 改动 | 解决什么 |
|---|---|---|
| **P0** | **H-2 关隘堡垒（Gate Fort）**：堡垒控制道路通行权 | L2 成为真正的「堡垒关」；该机制可复用为 L8 城墙门、L10 和平之门 |
| **P0** | **每关一个「记忆点」**（机制或美术），10 关 10 色 | 现在 L3/L4/L7 都是「占点 + 台词不同」，玩法辨识度低 |
| **P1** | 兑现 L5「退潮」台词 → 补 H-5 潮汐浅滩 | 台词承诺空头（见 `ACTION-PLAN.md` P0-3） |
| **P1** | 美术从「全人类=一种绿」升级为「一关一色 + 一关一个视觉符号」 | 手机小屏上十关长得一样 |

**最划算的一刀**：H-2 关隘堡垒。它是**唯一一个能同时被 L2 / L8 / L10 三关复用**的机制，一次投入、三关受益，且直接兑现黎总要的「堡垒控路」玩法。

## 1. 参考借鉴（外部同类游戏）

| 来源 | 可借鉴的点 | 我们怎么用 |
|---|---|---|
| **Mushroom Wars 2**（战役 100 关，建筑=村庄/锻炉/箭塔） | ① **箭塔守咽喉**：塔不产兵，专门卡路口；② **地块 modifier**：加速/减速/停止产兵的地面；③ **风推器**（wind pusher）：周期改变兵球移动；④ **洞穴**（类星际 Nydus Canal）：成对传送；⑤ 每关**开局态势不同**（以少打多、护送、坚守） | ①→ H-2 关隘堡垒；②→ H-1 焦土格（产兵减半，占领后复原）；③→ H-3 麦浪风；④→ 已规划矮人隧道，人类改用 H-6 粮船更贴题；⑤→ L4 坚守 / L9 斩首 / L10 三阶段已具备，再补「L7 以少打多」态势 |
| **State.io / Territorial.io** | ① 数字对撞、钳形攻势；② **切断补给线**（占中间格孤立敌军）；③ 先吃中立、后打人 | ②→ L2 三门渡口的核心乐趣（抢门 = 切断敌军增援）；③→ L1 教学的隐性课程（先吃中立村） |
| **Galcon / Nexus Wars** | 一指拖线派兵、极短决策周期 | 保持既有，不引入多步操作 |

> 一句话借鉴原则：**学「一个机制改变一张图的走法」，不学「加资源、加操作」**。

## 2. 人类线叙事重构（地理路线）

> **卷首语**：丰饶的人类王国四面受敌——这一次，狼烟同时烧到了四条边境。
> **叙事弧（三幕）**：**第一幕 守土**（L1–L4 从边境退到王畿）→ **第二幕 粮道**（L5–L6 抢回命脉）→ **第三幕 反攻**（L7–L9 一寸山河一寸血）→ **终章**（L10 和平之门）。
> **关键词**：麦田、江与桥、圣塔、粮道、烽火、王旗、晨光。

| 幕 | 关 | 地理 | 一句话剧情 |
|---|---|---|---|
| 一 | L1–L4 | 边境麦田 → 白龙江 → 内陆麦仓 → 王畿圣塔 | 火烧边境，退守国门之眼 |
| 二 | L5–L6 | 碎群岛粮道 → 谷仓重镇 | 粮道断则军心断 |
| 三 | L7–L9 | 沦陷村镇 → 三汊三角洲 → 王畿平原 | 一寸山河一寸血，反攻到王对王 |
| 终 | L10 | 王都门前 | 和平不是停战，是和平 |

## 4. 逐关详设

### L1 · 烽火边境（教学 · 改造）

| 项 | 内容 |
|---|---|
| **剧情** | 哥布林劫掠者趁夜越境烧了麦田。格瑞姆元帅传令：夺回每一寸被占的土地 |
| **地图** | 7×6 有机半岛，南侧一条小河；16 格左右。玩家 1 大本营 + 1 村在南，哥布林 ×2 在北。3~4 块「焦土格」沿火线分布 |
| **玩法** | 基础拖拽派兵；**H-1 焦土格**：产兵 ×0.5、容量 ×0.6，被玩家占领后 **20s 内逐步复原**为普通村（视觉：焦黑→冒烟→金黄麦田，麦穗粒子升起） |
| **美术** | 黄昏火烧云渐变（橙红→暗紫）+ 余烬上飘粒子 + 烧焦麦垛/断矛装饰 + 远处着火的谷仓剪影 |
| **教学** | 3 步：① 按住大本营拖向敌村（wait 'send'）② 占领任意村（wait 'capture'）③ 占满全图获胜 |
| **演出** | 保留既有「尾声哥布林援军杀出」（教回防）；新增：首次占领焦土村 → 运镜 + 军师「火灭了，地还在」 |
| **验收** | 焦土格复原前后产能对比（0.5 → 1.0）；教学三步不卡死；单局 ≤3 分钟 |

### L2 · **三门渡口**（堡垒关 · 重构）⭐ 本方案核心

> **改名已拍板（2026-09-08）**：原名「渡口阻击」→ 现名「**三门渡口**」。代码侧改名清单见第 9 章（**等 git 提交后再执行，本轮不动 `index.html`**）。

| 项 | 内容 |
|---|---|
| **剧情** | 白龙江横贯战场，**三处渡口**——白石桥、西津浅滩、东岭栈道。江心各立一座先王的关隘堡垒。占堡者，开门 |
| **地图** | 江（竖直水系）把图切成南（玩家 1 大本营 + 1 村）北（天龙 ×2）。江上只有 **3 个 gate 格**：`w`（西津浅滩）/ `B`（白石桥，中立碉堡沿用）/ `e`（东岭栈道）。每格紧邻一座**关隘堡垒**（中立，上限 12，×2 抵消同碉堡） |
| **核心规则 H-2** | ① gate 格**仅对堡垒归属方开放**，中立时双方都过不去；② 占领堡垒 → 闸门升起（0.6s 动画 + 号角音效），该路开通；③ **堡垒易主 8s 冷却**（`fortLock`），防止拉锯 —— 抢下就有 8 秒推兵窗口；④ 门关闭时，已在门外的己方兵球**不死亡**，改为原地徘徊/自动返航最近的己方据点（保红线：不惩罚到「看不懂」） |
| **玩法节奏** | 抢最近一座堡（半军：一半夺堡、一半守家）→ 开门推兵过江 → 敌反抢 → **门在自己身后关上**（此时需要召回/再开一门接应）→ 三门的取舍：开哪门 = 从哪路进攻 |
| **美术** | 江雾 + 铁灰石墙 + 木栈道；闸门是**可动件**（升起/落下），墙头旗帜随归属换色；关门时铁链声 + 溅水；白石桥沿用现有桥面 + 碉堡 |
| **教学** | 半军（夺堡要留一半守家）+ 召回（门被抢时把兵拉回）→ 与堡垒机制**天然咬合**，这是本关设计的最大收益 |
| **演出** | 首次开门：运镜推过桥面 + 军师「门开了——过江！」；门在身后关上：警报 + 对白「他们又把门合上了！」 |
| **演出/机制复用** | H-2 后续用于 L8 城门、L10 和平之门 |
| **验收** | ① 三 gate 在中立时双方均不可通行（e2e 断言）② 占堡后仅归属方可通行 ③ 易主 8s 冷却内不可再夺 ④ 关门时门外兵球不死且能返航 ⑤ 全图连通性（占至少一门后玩家可达敌方） |
