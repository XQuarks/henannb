## 1. 参考截图视觉分析

7 张图分两类风格：前 6 张是手绘绘本风（State.io 类），后 2 张是卡通描边风。可复用的「风格 DNA」如下：

| # | 特征        | 参考图做法                                                              | 我们的现状                                | 差距诊断                |
| - | --------- | ------------------------------------------------------------------ | ------------------------------------ | ------------------- |
| 1 | **整体轮廓**  | 陆地是有机剪影：完整岛屿（图2/5/8）、环形峡谷（图1）、弯月（图4），**无外框、铺满屏幕**，陆地直接「漂」在水色背景上    | 树状大陆细长瘦弱，只占屏幕中央 40\~60%，四周大面积深灰留白    | 形状随机但「不像一块地方」，像一团细胞 |
| 2 | **一图一生态** | 每张图整套换色：水色（浅蓝/冰蓝/深青）+ 地色（草绿/沙橙/雪白/暗紫/炭褐）+ 装饰色，6 张图 6 个世界           | 全部关卡共用 `#17181b` 深炭底 + `#26282d` 深灰地 | 四族 40 关视觉上是一个地方     |
| 3 | **内部空洞**  | 陆地内部挖大面积不可通行区（湖、岩区、熔岩），形成环、弯月、裂谷等**功能性形状**（图1 中央双空洞、图4 纵向裂谷）       | 有 LAKES/MOUNTAINS 但规模小（1\~3 格）、位置随机  | 空洞没有「塑造形状」，只是撒点     |
| 4 | **装饰成簇**  | 森林/蘑菇林/枯树林/沙丘**成大片簇群**、不对称分布，占屏比 15\~30%，是构图的一部分（图2 左上森林、图6 右侧蘑菇林） | `drawProps()` 只有零星小岩石/枯木点缀           | 装饰没有体量感，撑不起氛围       |
| 5 | **领地辨识度** | 区域色块饱和度高、描边粗，敌我一眼可辨；数字/图标居中清晰                                      | 领地色只有 `col+"26"`（15% 透明度）薄涂，深色地上偏暗   | 手机小屏上敌我边界不够「爽」      |
| 6 | **障碍即地形** | 不可通行物（海、湖、岩、林）就是地图外形的雕刻刀，同时是路径设计的依据                                | 山体/湖泊与路径设计基本无关                       | 障碍没有参与「关卡结构」        |

**提炼成三条设计原则**：

1. **外形先行**——先有一块「像地方」的大陆剪影，再在里面分格子；
2. **生态成套**——水色/地色/障碍/装饰/事件五件套一起换，不是只换地色；
3. **障碍参与结构**——湖、山、林、熔岩的位置由关卡结构决定，不做随机撒点。

## 2. 大陆架轮廓层（解需求 1：打破方形/瘦弱地图）

### 2.1 两层分离的生成管线

现状：`genSkeleton()` 的脊柱形状 = 地图全部形状，所以只能是「树/桥/走廊」这类一维结构。
改造：在骨架之前插入**轮廓层**——

```
① 轮廓层 genCoastline(shape)  → 一条闭合有机海岸线（超椭圆 + 噪声扰动 + 缺口雕刻）
② 骨架层 genSkeleton(mode)   → 现有 M0~M5 不变，但只在海岸线内部播种
③ 泊松填充 + Voronoi        → 现有管线不变，轮廓外候选格直接判为「海」
④ 障碍雕刻                  → 按关卡结构表放置湖/山/林（不再是随机修饰词）
```

海岸线生成参数：基础超椭圆（控制圆/方/长条）→ 2\~4 段低频噪声扰动边缘（Chaikin 平滑同款手法）→ 按模板雕刻缺口（海湾/裂口）。种子驱动，固定地图照旧可复现。

### 2.2 六种外形模板（与 M0\~M5 正交组合）

| 模板           | 外形                | 内部结构特征        | 玩法含义              | 首选归属            |
| ------------ | ----------------- | ------------- | ----------------- | --------------- |
| **S1 新月湾**   | 弯月形陆地环抱一片海湾       | 沿湾单向链 + 湾口捷径桥 | 绕行 vs 抢捷径的抉择      | 人类 L4/L8        |
| **S2 碎群岛**   | 2\~4 块岛屿 + 桥/浅滩相连 | 岛间咽喉格成串       | 逐岛争夺，海军式跳岛        | 哥布林 L9、自由对战     |
| **S3 环形湖心**  | 环形陆地抱中心大湖         | 环湖单向 + 湖心岛    | 「湖心」名正言顺；M1 的正解   | 天龙 L8、人类 L8     |
| **S4 裂谷峡谷**  | 两堵陆墙夹一条纵向裂谷       | 谷内 1\~2 条通路   | 正面冲撞、无法迂回         | 矮人 L8、天龙 L2     |

## 4. 四族地理叙事线（解需求 2/3：剧情差异 + 区域重规划）

核心思路：**每族的 10 关是在同一个世界里推进的一条地理路线**——玩家看着地图从边境一路打到敌方腹地，区域分布、路径结构、外形模板都为这条叙事服务。这解决「四族换皮不换图」，也让每关的区域分布有剧情依据。

## 5. 地图交互：拖拽、缩放与导航（需求 4）

### 5.1 手势方案（不破一指红线）

| 手势             | 通道 | 行为                 |

| 双指捏合 / 双指拖动    | 新增 | 缩放（0.7×\~2.5×）/ 平移 |
| 桌面滚轮 / 右键拖动    | 新增 | 缩放 / 平移            |
| 双击空白           | 新增 | 复位视图（回到全景）         |

实现：`cam` 已有 `zoom/x/y`（终局推镜在用，`index.html:5101`），把它从「演出专用」升级为常驻相机：平移加惯性衰减、边界钳制（地图外缘 +15% 软边界）、缩放锚点=双指中心。拖拽派兵的引导线/预测线在世界坐标系下绘制，相机变换后自然正确。

### 5.2 与既有操作的冲突排查

- ½ 钮/✦ 技能/⚑ 集结全部是 DOM 按钮，不走 canvas 手势，无冲突。

- 召回是「点出发村」，平移是「拖空白」，位移 <10px 视为点击的既有容错继续生效。

- 多指派兵（pointerId 隔离）与双指平移的仲裁：**第二指落下时若第一指正在派兵拖拽，则第一指手势取消并召回未出发球**（等同拖出地图取消），避免一边派兵一边转视角的混乱。

## 8. 风险与开放问题（拍板前请过目）

1. **地图放大后的平衡**：格子翻倍后单局时长可能突破 6 分钟红线——批次 A 必须实测，必要时产能/移速随格数缩放（数值进 CFG，不散落硬编码）。
2. **小屏性能**：50 格 + 装饰簇 + 粒子，DPR≤2 的既有上限下需复测帧率；装饰簇建议离屏缓存成一张静态层（每局只画一次）。
3. **矿洞隧道是四个机制里唯一动路径结算的**，成本最高，若批次 C 工期紧张可降级为「隧道格移速 ×2 的山中捷径」。
4. **生态皮肤的领地辨识度**：浅色生态（矮人雪原）上现有的深色描边方案要反转为深色描边 + 亮色薄涂，批次 B 预览时重点确认。
5. **M2 三叶债**：S6 三角洲在 30+ 格地图上应当稳定，但仍需保留「生成失败降级为环形湖」的兜底（与现有挖湖降级同款思路）。
